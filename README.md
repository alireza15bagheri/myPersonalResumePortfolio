# Alireza Bagheri — Personal Portfolio

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A modern, responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript. Showcases frontend development skills, projects, and experience through clean architecture and accessible interactions.

**Live Demo:** [https://alirezapersonal.ir/](https://alirezapersonal.ir/)

---

## Key Features

- Fixed sidebar navigation with profile, links, and GitHub
- Typewriter animation with rotating phrases
- 3D portfolio card hover effect (mouse-tracking CSS transforms)
- Responsive hamburger menu with animated transition
- Contact form with client-side validation (Formspree)
- Native smooth scrolling and scroll-to-top button
- SEO meta tags (Open Graph, Twitter Cards)
- WCAG 2.1 AA accessibility patterns

---

## Technology Stack

| Category | Technologies |
|----------|--------------|
| **Core** | HTML5, CSS3 (Custom Properties, Flexbox, Grid), Vanilla JavaScript (ES6+) |
| **CDN** | Font Awesome 6.2.1 (async), Google Fonts (Nunito, preconnect) |
| **Services** | Formspree (form endpoint) |

No build tools, bundlers, or dependencies required.

## Installation & Usage

```bash
# Clone and run locally
git clone https://github.com/alireza15bagheri/myPersonalResumePortfolio.git
cd myPersonalResumePortfolio

# Any static server:
npx serve .          # or: python -m http.server 8000
# Then open http://localhost:3000 (or 8000)
```

Open `index.html` directly in a browser for zero-setup viewing.
